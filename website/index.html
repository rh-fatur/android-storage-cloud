Android Storage Cloud
Cara kerja Mulai Perintah Keamanan Masalah umum GitHub

HP lama Anda, jadi cloud pribadi.

Ubah HP Android bekas menjadi penyimpanan di rumah dengan Termux, SSH, dan Filebrowser. Unggah, unduh, dan bagikan file dari browser tanpa biaya langganan.

Mulai setup Lihat di GitHub

Untuk HP Android 9–11 64-bit. Tanpa root.

Dua perangkat, tugas terpisah

HP menyimpan dan melayani file. Laptop hanya mengendalikannya dari jauh.

Laptop atau PC admin

Menjalankan admin/cloudctl. Mengirim skrip, memulai layanan, menarik backup. Tidak menyimpan file cloud.

SSH, port 8022

HP server

Menjalankan server/cloudctl dengan sshd dan Filebrowser. Menyimpan semua file di folder CloudStorage.

Pengguna biasa tidak perlu admin. Cukup buka http://IP-HP:8080 di browser, dari Wi-Fi rumah atau lewat Tailscale dari luar.

Yang perlu disiapkan

HP server
Android 9–11, 64-bit (aarch64), RAM minimal 3 GB (2 GB cukup untuk beban ringan), charger dan tempat yang berventilasi baik.
Aplikasi di HP
Termux dan Termux:Boot dari GitHub Releases atau F-Droid, bukan Google Play Store. Keduanya harus dari sumber yang sama. Tailscale bersifat opsional.
Perangkat admin
Linux, macOS, atau Windows dengan WSL/Git Bash. Butuh ssh, scp, dan tar.

Mulai dalam lima langkah

Langkah 1 dilakukan langsung di HP. Sisanya dari laptop.

  1. Siapkan SSH di HP Di HP

    Buka Termux, izinkan akses storage, lalu nyalakan SSH. Catat username dari whoami dan IP HP.

    termux-setup-storage
pkg install -y openssh
passwd
whoami
sshd

  2. Hubungkan laptop ke HP Di laptop

    Unduh proyek, lalu jalankan init. Anda akan diminta IP dan username HP. Kunci SSH dibuat dan dipasang otomatis.

    git clone https://github.com/rh-fatur/android-storage-cloud.git
cd android-storage-cloud
./admin/cloudctl init

  3. Pasang dan jalankan server Di laptop

    Skrip dikirim ke HP, lalu Filebrowser diinstal dan dijalankan.

    ./admin/cloudctl setup
./admin/cloudctl start

  4. Aktifkan auto-start dan amankan SSH Di laptop

    Server menyala sendiri setelah HP restart, dan login password SSH dimatikan. Buka aplikasi Termux:Boot di HP satu kali, lalu matikan optimasi baterai untuk Termux dan Termux:Boot.

    ./admin/cloudctl boot-install
./admin/cloudctl ssh-harden

  5. Masuk ke Filebrowser Di laptop

    Buka Web UI, lalu cari password admin awal di log. Versi Filebrowser terbaru membuat password acak yang dicetak di log. Segera ganti di Settings → Profile Settings dan buat akun terpisah per pengguna.

    ./admin/cloudctl open
./admin/cloudctl logs

Jaga tetap privat

Server di rumah aman selama tidak dibuka ke internet publik.

  • Jangan buka port ke internet. Hindari port forward untuk 8080 dan 8022. Untuk akses dari luar rumah, pakai Tailscale dan isi CLOUD_HOST dengan IP Tailscale HP.
  • Pakai kunci SSH. Setelah init berhasil, jalankan ssh-harden. Simpan kunci privat ~/.ssh/id_ed25519_cloud. Jika hilang, akses ulang lewat Termux langsung di HP.
  • Ganti password default dan pisahkan akun. Buat satu akun Filebrowser per pengguna dengan batasan folder.
  • Backup tidak mencakup file Anda. backup hanya menyimpan database dan konfigurasi. Salin isi folder cloud secara terpisah dengan pull atau SFTP.
  • Rawat baterai. Pakai charger standar, beri ventilasi, dan pertimbangkan pembatas pengisian (misalnya ACC pada HP yang sudah root) untuk pemakaian 24/7.

Masalah umum

Cek di sini sebelum membuka isu baru.

init gagal tersambung

Pastikan sshd berjalan di HP, IP benar, kedua perangkat satu jaringan, dan port 8022 yang dipakai.

setup berhenti dengan pesan “Akses storage belum diberikan”

Izin storage tidak bisa diberikan lewat SSH. Jalankan termux-setup-storage langsung di HP, izinkan, lalu ulangi setup.

Server mati saat layar padam

Matikan optimasi baterai untuk Termux. Wake-lock dipasang otomatis oleh start.

Server tidak menyala setelah HP restart

Buka Termux:Boot satu kali, cek server/data/boot.log di HP, lalu ulangi boot-install.

Port 8080 sudah dipakai

Jalankan ./admin/cloudctl config, ubah FB_PORT, lalu restart. Ubah juga FB_PORT di admin/config/admin.env.

Filebrowser gagal diunduh

Cek koneksi internet HP. GitHub API membatasi jumlah permintaan, jadi coba lagi beberapa menit kemudian.

Tidak bisa SSH setelah stop --all

Perintah itu ikut mematikan sshd. Nyalakan lagi langsung dari HP dengan perintah sshd.
